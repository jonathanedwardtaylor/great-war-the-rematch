# Great War: The Rematch

An HTML5 turn-based tactics game project inspired by compact, readable mobile strategy games, with an original World War 1 theme and mechanics.

## Project Status

Current phase: setup and design exploration.

The first playable goal is a small skirmish prototype with:

- One battlefield map
- Two opposing sides
- A small set of unit types
- Touch-friendly selection, movement, attack, and end-turn flow
- A clear win/loss condition

## Planned Stack

- TypeScript
- Phaser
- Vite
- Vitest
- Playwright
- Vercel for web previews
- Capacitor later for mobile app packaging

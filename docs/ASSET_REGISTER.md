# Asset Register

Track every external or generated asset considered for the game.

This matters because the project may become commercial. If an asset enters the repo, we should know where it came from, whether it can be used commercially, and whether it was modified.

## Rules

- Do not add unclear-license assets to the game.
- Keep source files when possible.
- Prefer original generated, commissioned, public-domain, or explicitly commercial-safe assets.
- Record prompt text for generated assets when practical.
- Do not use copyrighted references as direct production input.

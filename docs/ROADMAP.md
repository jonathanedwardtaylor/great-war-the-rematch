# Roadmap

## Phase 0: Project Setup

- Create repository.
- Add starter documentation.
- Choose initial tech stack.
- Create initial code scaffold.
- Add basic build and test scripts.

## Phase 1: First Playable

- Render one battlefield.
- Add unit selection.
- Add movement.
- Add attacks.
- Add turn switching.
- Add win/loss condition.
- Add basic mobile viewport support.

## Phase 2: Prototype Skirmish

- Add two or three unit types.
- Add terrain movement and defense rules.
- Add simple enemy behavior.
- Add basic sound and animation feedback.
- Add restart flow.

## Phase 3: Vertical Slice

- One polished mission.
- Improved UI.
- Clear art direction.
- Basic menu flow.
- Tested deployment preview.

## Later

- Campaign map.
- Progression.
- Mobile app packaging.
- App store payment strategy.
- Cloud saves or leaderboards if needed.

# Game Design

## Core Loop

1. Inspect battlefield.
2. Select a unit.
3. Move or hold position.
4. Attack, capture, repair, or use a special action.
5. End turn.
6. Enemy responds.
7. Repeat until victory or defeat.

## Player Experience Goals

- Turns should be quick.
- Unit roles should be obvious.
- Terrain should create interesting choices.
- Losses should feel understandable rather than random.
- The interface should be comfortable on phones.

## Prototype Unit Ideas

- Infantry: flexible ground unit, good for capturing objectives.
- Machine gun team: defensive unit, strong overwatch or suppression potential.
- Field gun: long-range artillery, slow and vulnerable.
- Light tank: durable breakthrough unit.

## Prototype Terrain Ideas

- Open ground
- Trench
- Mud
- Forest
- Road
- Crater
- Objective tile

## Questions To Resolve

- Square grid, hex grid, or isometric square grid?
- Should attacks be deterministic or probability-based?
- Should morale/suppression exist in the first prototype or later?
- Should the first enemy be scripted, rule-based AI, or hot-seat only?

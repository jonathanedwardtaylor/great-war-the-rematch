# Vision

## One-Line Pitch

A compact, mobile-friendly World War 1 tactics game where readable battlefield decisions matter more than micromanagement.

## Design Intent

The game should feel approachable, tactical, and replayable. Battles should be readable at a glance, with short turns, satisfying unit interactions, and enough terrain variety to make positioning matter.

## Creative Boundaries

- Create an original game identity, not a clone of any existing game.
- Use World War 1 as inspiration for tone, units, terrain, and tactical problems.
- Keep the visual style stylized rather than realistic or grim.
- Prioritize clarity on small mobile screens.
- Build the smallest playable version first.

## First Playable Definition

The first playable version should let a player start one skirmish, move units, attack enemy units, end turns, and win or lose.

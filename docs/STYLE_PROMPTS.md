# Style Prompts

Use this file to collect reusable visual prompts for concept art, art direction, and later production asset planning.

The goal is to create an original visual identity: stylized, readable, mobile-friendly, and World War 1 inspired without copying any existing game.

## Core Visual Direction

```text
Stylized mobile turn-based tactics game, original World War 1 inspired setting, toy-like battlefield miniatures, readable isometric tiles, chunky unit silhouettes, trenches, craters, mud, early tanks, field guns, sandbags, muted olive green and khaki palette with warm parchment UI accents, charming strategy-game tone, clean shapes, high readability on phone screens, not realistic, not grimdark, not a clone of any existing game.
```

## Negative Direction

Avoid:

- Photorealism
- Modern military equipment
- Horror or gore
- Overly detailed textures that become noisy on mobile
- Direct references to existing game art, UI, characters, logos, or layouts
- Tiny unreadable unit details
- Monochrome mud-only palettes

## Concept Image Prompts

### Battlefield Mood Concept

```text
Create a concept image for an original stylized World War 1 mobile tactics game. Show an isometric toy-like battlefield with trenches, shell craters, muddy roads, sandbags, sparse trees, and small readable unit miniatures. The style should be charming, tactical, and readable on mobile, with chunky shapes, soft shadows, muted olive, khaki, slate, and warm parchment colors. No gore, no photorealism, no existing game references.
```

### Unit Lineup Concept

```text
Create a concept lineup of original stylized World War 1 tactics units for a mobile game: infantry, machine gun team, field gun crew, light tank, medic, and officer. Use toy-like proportions, chunky silhouettes, clear team-color accents, readable shapes for small screens, and a warm muted palette. The units should feel charming and tactical, not realistic or grim. No copied characters, logos, or existing game style.
```

### Terrain Tile Concept

```text
Create a concept sheet of isometric terrain tiles for an original World War 1 mobile tactics game. Include open ground, trench, mud, road, crater, forest, barbed wire, sandbag position, and objective tile. Each tile should be readable at small size, stylized, chunky, and designed for a turn-based tactics grid. Use muted earthy colors with clear contrast between tile types. No photorealism.
```

### Mobile UI Concept

```text
Create a mobile game UI concept for an original World War 1 turn-based tactics game. Show a battlefield with compact bottom action buttons, unit info, turn indicator, health, movement and attack icons, and a clean readable command layout. Use parchment, brass, olive, and muted red/blue team accents. The UI should be touch-friendly, uncluttered, and readable on a phone screen. No existing game references.
```

## Production Asset Notes

Concept images are for direction only. They should not be treated as final production assets until the grid scale, camera angle, unit size, and animation requirements are known.

Before using any generated or external asset in the game, record it in `docs/ASSET_REGISTER.md`.
